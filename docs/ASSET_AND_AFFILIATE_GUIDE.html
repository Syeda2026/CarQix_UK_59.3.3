MyUsedCarSaleUK — Asset Customization & Affiliate Network Guide

Comprehensive documentation for replacing app assets and joining UK automotive affiliate networks.

Part 1: How to Replace / Update All Images, Icons & Branding

1. App Launcher Icon & Adaptive Logo

Files: res/drawable/ic_launcher_foreground.xml, res/drawable/ic_launcher_background.xml, res/mipmap-*/ic_launcher.xml

  • Open project in Android Studio. Right-click app directory → New → Image Asset.
  • Select Launcher Icons (Adaptive and Legacy). Choose your logo PNG/SVG for Foreground Layer and color for Background Layer.

2. Splash Screen & App Logo

Files: res/drawable/ic_used_cars_logo_car.xml, res/drawable/splash_background.xml

  • Replace ic_used_cars_logo_car.xml in res/drawable/ with your brand's vector SVG logo.

3. Hero Banners & Section Backgrounds

Files: res/drawable/ic_car_hero_bg.xml, common/Components.kt

  • Add custom banners to res/drawable/ and load them with painterResource(R.drawable.your_hero_image) or Coil's AsyncImage for remote URLs.

Part 3: Updating Affiliate Tracking Links in Code

Update links in app/src/main/java/com/aaapp/appguru/myusedcarsaleuk/core/config/AffiliateConfig.kt:

"autotrader" to PartnerUrlConfig(
    partnerId = "autotrader",
    name = "AutoTrader",
    publicUrl = "https://www.autotrader.co.uk/car-search",
    affiliateUrl = "https://www.awin1.com/cread.php?awinmid=YOUR_MID&awinaffid=YOUR_AFFILIATE_ID&p=https://www.autotrader.co.uk/car-search",
    isEnabled = true,
    priority = 1
)
